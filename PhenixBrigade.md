## Cache Exorcism — Deep Cleanse

When `expo-build-properties` haunts you:

```bash
npm cache clean --force
rm -rf node_modules package-lock.json
rm -rf ~/Library/Caches/eas-cli
rm -rf ~/.eas
npm install
```

Or invoke Charlie:
```bash
./scripts/charlie.sh
```

Then rebuild:
```bash
npx eas-cli build --platform ios --profile production --clear-cache
```

Always fresh. Always organic. Always precisecement.
